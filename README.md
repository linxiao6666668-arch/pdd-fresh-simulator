# 拼多多生鲜模拟系统（买家端）

一套**纯前端**的拼多多生鲜购物流程模拟系统，仿「多多买菜」风格。无需后端、无需安装，浏览器直接打开即可体验完整购物链路。

## 功能

- **首页浏览**：品类频道（水果 / 蔬菜 / 肉禽蛋 / 水产 / 粮油 / 乳品）、产地直发横幅、限时秒杀（实时倒计时）、商品推荐栅格
- **搜索与筛选**：顶部搜索框实时过滤，品类标签一键切换
- **商品详情**：实拍商品图、划线价 / 拼团价、产地与配送信息、服务保障、数量选择、加入购物车 / 立即购买
- **拼单模拟**：发起 2 人拼团，拼团成功后订单带拼团标记
- **购物车**：勾选、数量增减、删除、全选、合计金额
- **确认订单**：收货地址选择、今日达配送、优惠券自动最优抵扣、运费满 29 免、支付方式选择
- **下单与订单**：下单支付成功页；订单列表按状态分页（待发货 / 已发货 / 已完成）；「模拟发货」「确认收货」驱动物流时间线；再次购买一键回填购物车

## 技术实现

- 单文件 HTML（`index.html`），内联 CSS 与原生 JavaScript，无框架、无构建
- Hash 路由多视图：首页 / 分类 / 商品详情 / 购物车 / 结算 / 下单成功 / 订单列表 / 订单详情
- 数据（商品、地址、优惠券、支付方式）内联于 JS；购物车与订单持久化到 `localStorage`
- 响应式：移动端底部 Tab 导航 + 双列栅格，桌面端顶部导航 + 四列栅格
- 商品图与横幅为 AI 生成的电商棚拍素材，存放于 `assets/`

## 运行方式

1. 直接双击打开 `index.html`（本地即可运行，无需服务器）
2. 或将仓库部署到 GitHub Pages / 任意静态托管，访问站点地址即可

> 说明：本系统为演示用途，商品、价格、销量、地址、优惠券等均为内置模拟数据，不产生真实交易。

## 交互路径示例

浏览/搜索 → 商品详情 → 加入购物车（或立即购买 / 发起拼单）→ 购物车结算 → 确认订单（选地址/优惠券/支付方式）→ 提交订单 → 订单列表 → 模拟发货 → 物流跟踪 → 确认收货 → 再次购买
